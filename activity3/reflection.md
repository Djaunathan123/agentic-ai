## 3. Reflection: Why did we have to send `[user_query, response.text, observation]` as a list in Turn 2?

We send `[user_query, response.text, observation]` as a list so the model has the complete context of the interaction. The `user_query` contains the original question, `response.text` includes the tool request generated by the model, and `observation` provides the simulated tool result. By passing all three together, the model can understand the previous steps and generate a final answer that correctly uses the information from the tool.
