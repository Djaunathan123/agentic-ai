# Self-Reflection: How does using a strict Enum (Severity) prevent model hallucination compared to letting the model output any string for severity level?
## - Using a strict Severity Enum restricts the model to only three valid values: LOW, MEDIUM, and HIGH. This prevents it from generating unexpected or inconsistent labels such as "Very High", "Critical", or "Moderate-High", which could cause validation failures or inconsistent data. By enforcing a fixed set of allowed values, the Enum improves reliability, standardization, and data integrity in the structured medical intake record.
